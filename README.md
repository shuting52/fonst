# FontDesign-skill

一个万能字体设计与生图提示词专家 Skill。

它会根据用户输入的文字内容、风格偏好、使用场景，自动匹配最佳字体类型，并输出可直接用于生图工具的字体设计规范和提示词。

## 适用场景

- 电竞战队LOGO设计
- 品牌标识与商业字体
- 个人姓名定制字体
- 3D立体字体设计
- 励志主题艺术字
- 爱情主题字体设计
- 爱国主题字体设计
- 封面标题字体
- 艺术创意字体
- 参考图风格复刻

## 输出内容

Skill 默认输出中文内容，包括：

- 内容判断与分类
- 推荐字体类型
- 匹配原因分析
- 设计规范说明
- 单张图正向生图提示词
- 负面提示词
- 可替换文字建议
- 是否可以继续调用生图工具的引导语

## 生图策略

这个 Skill 是 prompt-first，不会默认直接生成图片。

如果当前环境支持生图工具，它只会先询问用户是否需要直接生成。只有用户明确回复"生成""直接做""调用 image""帮我出图"等指令时，才会继续调用生图工具。

如果当前环境不支持生图，它会输出可复制的提示词，供 GPT-image、即梦、Midjourney 或其他工具使用。

## 设计规则

- 聚焦单张字体设计，不默认输出合集图
- 保留用户提供的文字内容
- 先分析参考图的设计语言，再迁移风格
- 提示词必须包含文字内容、字体风格、材质、色彩、光影、背景和负面约束
- 中文文字生成存在不稳定性，正式发布前建议在设计工具中覆盖关键文字
- 支持中英双语输出

## 使用方式

将本仓库放入 Codex skills 目录后，在对话中说明需求，例如：

```text
帮我设计一个电竞战队LOGO，队名是"九域电竞"。
```

```text
帮我做一个3D金属质感的"前程似锦"艺术字。
```

```text
设计一个情侣姓名字体，男生姓李，女生姓吴。
```

```text
根据这张参考图，帮我设计一个"天涯人"字体。
```

```text
帮我做一个爱国主题的"中国加油"字体设计。
```

## 特色功能

### 千款提示词模板
内置丰富的字体设计提示词模板，覆盖：
- 47+ 电竞战队LOGO示例
- 56+ 3D立体字体示例
- 多种材质质感（金属、水晶、玉石、木材、霓虹等）
- 多种主题风格（励志、爱情、爱国、艺术等）

### 智能分类匹配
根据用户输入自动识别最佳字体类型：
- 文字内容分析
- 风格偏好识别
- 使用场景判断
- 参考图风格提取

### 专业设计规范
输出包含完整的设计规范：
- 图形构成分析
- 色彩方案建议
- 字体风格指导
- 装饰元素建议

## 注意事项

- AI生图对中文文字的渲染可能不够精准，建议生成后在设计软件中进行文字精修
- 复杂的字体设计可能需要多次迭代优化
- 建议提供参考图以获得更精准的风格匹配
- 电竞LOGO类设计建议同时提供中英文队名
